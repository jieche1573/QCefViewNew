# 流程图管理接口文档

## 概述

流程图管理模块用于保存和管理飞机维修流程图数据。采用纯JSON存储方案，将流程图的节点、连接等信息完整保存在数据库中。

## 数据结构

### 流程图记录结构

```json
{
  "id": "20251108232312345678ABC",
  "model_id": "20251109144639678678cc1ae7",
  "model_name": "歼二十",
  "name": "飞行前检查",
  "implement_node": "首次起飞前",
  "level": "一级",
  "graph_data": {
    "nodes": [...],
    "edges": [...]
  },
  "create_time": "2025-11-08 23:23:12",
  "update_time": "2025-11-08 23:23:12"
}
```

### graph_data结构说明

```json
{
  "nodes": [
    {
      "id": "start",
      "type": "start",
      "x": 400,
      "y": 80
    },
    {
      "id": "node1",
      "type": "person",
      "x": 400,
      "y": 200,
      "name": "检查外观",
      "personId": "20251110103015678678cc1ae7",
      "personName": "钳工师",
      "prepareTime": 10,
      "workTime": 30,
      "finishTime": 5
    },
    {
      "id": "node2",
      "type": "personCar",
      "x": 400,
      "y": 320,
      "name": "加油作业",
      "personId": "20251110103015684684086dfc",
      "personName": "特工",
      "carId": "2",
      "carName": "加油车",
      "prepareTime": 15,
      "workTime": 45,
      "finishTime": 10
    },
    {
      "id": "end",
      "type": "end",
      "x": 400,
      "y": 500
    }
  ],
  "edges": [
    {
      "id": "start-node1",
      "from": "start",
      "to": "node1"
    },
    {
      "id": "node1-node2",
      "from": "node1",
      "to": "node2"
    },
    {
      "id": "node2-end",
      "from": "node2",
      "to": "end"
    }
  ]
}
```

**节点类型说明：**
- **start**: 开始节点（无需时间字段）
- **end**: 结束节点（无需时间字段）
- **person**: 有人节点（需要岗位 + 时间字段）
- **personCar**: 有人有车节点（需要岗位 + 设备 + 时间字段）

**时间字段说明（person 和 personCar 类型节点）：**
- **prepareTime**: 准备时间（分钟）
- **workTime**: 工作时间（分钟）
- **finishTime**: 收尾时间（分钟）

## 使用场景

### 场景1: 创建新流程图

前端绘制流程图后，将完整的节点和边数据打包成JSON，调用添加接口保存。

```javascript
const flowData = {
  model_id: selectedModelId,
  name: "飞行前检查",
  implement_node: "首次起飞前",
  level: "一级",
  graph_data: {
    nodes: [...], // 从流程图编辑器获取
    edges: [...]  // 从流程图编辑器获取
  }
};

qtClient.queryProcessAddReq(JSON.stringify(flowData));
```

### 场景2: 加载流程图

根据ID加载流程图，直接使用graph_data渲染。

```javascript
qtClient.queryProcessReq();
qtClient.queryProcess.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);
  result.data.forEach(flow => {
    // 直接使用flow.graph_data渲染流程图
    renderFlowGraph(flow.graph_data);
  });
});
```

### 场景3: 统计分析

查看某个岗位在哪些流程中被使用：

```javascript
qtClient.queryProcessByPersonIdReq(personId);
qtClient.queryProcessByPersonId.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);
  console.log(`该岗位在${result.count}个流程中被使用`);
});
```

### 场景4: 按机型筛选流程

```javascript
qtClient.queryProcessByModelIdReq(modelId);
qtClient.queryProcessByModelId.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);
  // 显示该机型的所有流程
  displayFlowList(result.data);
});
```

## 注意事项

1. **graph_data完整性**：
   - 必须包含nodes数组和edges数组
   - 每个节点必须有唯一的id
   - 边的from/to必须对应已存在的节点id

2. **时间字段要求**：
   - person 和 personCar 类型节点必须包含时间字段：prepareTime、workTime、finishTime
   - 时间单位为分钟，必须为数字类型
   - start 和 end 节点无需时间字段

3. **节点信息冗余**：
   - personName和carName等冗余信息方便前端显示
   - 但岗位/设备名称修改后，已保存的流程图不会自动更新
   - 建议在加载时根据ID重新查询最新名称

4. **性能考虑**：
   - queryByPersonId和queryByCarId需要解析所有流程图的JSON
   - 数据量大时性能可能受影响
   - 建议前端做缓存优化

5. **数据一致性**：
   - 删除岗位/设备前应检查是否被流程图使用
   - 可通过queryByPersonId/queryByCarId检查

## 字段说明

### 流程图主字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 流程图唯一ID |
| model_id | String | 机型ID（关联aircraft_model表） |
| model_name | String | 机型名称（查询得到） |
| name | String | 流程名称 |
| implement_node | String | 实施节点 |
| level | String | 等级 |
| graph_data | Object | 流程图JSON数据 |
| create_time | String | 创建时间 |
| update_time | String | 更新时间 |

### 节点字段说明（graph_data.nodes）

#### 通用字段（所有节点类型）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 节点唯一标识 |
| type | String | 节点类型（start/end/person/personCar） |
| x | Number | 节点X坐标 |
| y | Number | 节点Y坐标 |

#### person 节点特有字段
| 字段 | 类型 | 说明 |
|------|------|------|
| name | String | 节点名称/任务名称 |
| personId | String | 岗位ID |
| personName | String | 岗位名称（冗余字段） |
| prepareTime | Number | 准备时间（分钟） |
| workTime | Number | 工作时间（分钟） |
| finishTime | Number | 收尾时间（分钟） |

#### personCar 节点特有字段
| 字段 | 类型 | 说明 |
|------|------|------|
| name | String | 节点名称/任务名称 |
| personId | String | 岗位ID |
| personName | String | 岗位名称（冗余字段） |
| carId | String | 设备ID |
| carName | String | 设备名称（冗余字段） |
| prepareTime | Number | 准备时间（分钟） |
| workTime | Number | 工作时间（分钟） |
| finishTime | Number | 收尾时间（分钟） |
