# 想定管理前端接口文档

## 概述

本文档描述前端通过WebSocket与后端交互的想定管理接口。所有接口通过 `qtClient` 对象调用，数据格式为JSON。

---

## 接口列表

**前端调用：**

```javascript
qtClient.queryScenarioReq();
```

### 2. 添加想定记录

**前端调用：**
```javascript
// 构造要添加的数据
var newScenario = {
    "xdmc": "2025年10月15日 夜间飞行训练",
    "jc": "连城机场",
    "zt": "草稿",
    "xdms": "夜间飞行训练计划，包含夜间起降和导航科目",
    "kssj": "2025-10-15 20:00:00",
    "jssj": "2025-10-16 02:00:00"
};

// 发送请求
qtClient.queryScenarioAddReq(JSON.stringify(newScenario));

// 监听返回结果
qtClient.queryScenarioAdd.connect(function (jsonStr) {
    console.log("添加成功：", jsonStr);
    // jsonStr 包含完整的新记录，包括自动生成的 id
});
```

**请求参数说明：**
- `xdmc`: 想定名称（必填）
- `jc`: 机场（选填）
- `zt`: 状态，建议值：草稿、进行中、已完成（选填）
- `xdms`: 想定描述（选填）
- `kssj`: 开始时间，格式：yyyy-MM-dd HH:mm:ss（选填）
- `jssj`: 结束时间，格式：yyyy-MM-dd HH:mm:ss（选填）

**返回JSON结构：**
成功时返回完整的新记录（包含自动生成的id和时间戳）
```json
{
    "id": "20251108232612345678JKL",
    "xdmc": "2025年10月15日 夜间飞行训练",
    "jc": "连城机场",
    "zt": "草稿",
    "xdms": "夜间飞行训练计划，包含夜间起降和导航科目",
    "kssj": "2025-10-15 20:00:00",
    "jssj": "2025-10-16 02:00:00",
    "ryzddlyl": 0.00,
    "zbzddlyl": 0.00,
    "rymzl": 0.00,
    "zbmzl": 0.00,
    "create_time": "2025-11-08 23:26:12",
    "update_time": "2025-11-08 23:26:12"
}
```

失败时返回空字符串 `""`

**注意：** 新添加的记录，利用率和满足率字段默认为 0.00

### 3. 删除想定记录

**前端调用：**
```javascript
// 发送删除请求（传入想定ID）
qtClient.queryScenarioDelReq("20251108232312345678ABC");

// 监听返回结果
qtClient.queryScenarioDel.connect(function (ok) {
    if (ok) {
        console.log("删除成功");
    } else {
        console.log("删除失败");
    }
});
```

**请求参数：**
- 想定记录的唯一ID（字符串类型）

**返回值：**
- `true`: 删除成功
- `false`: 删除失败

### 7. 更新想定的利用率和满足率字段

**前端调用：**
```javascript
// 构造要更新的利用率和满足率数据（必须包含id字段）
var updateRateData = {
    "id": "20251108232312345678ABC",
    "ryzddlyl": 0.85,  // 人员最大利用率
    "zbzddlyl": 0.92,  // 装备最大利用率
    "rymzl": 0.78,     // 人员满足率
    "zbmzl": 0.88      // 装备满足率
};

// 发送请求
qtClient.updateScenarioRateFieldsReq(JSON.stringify(updateRateData));

// 监听返回结果
qtClient.updateScenarioRateFields.connect(function (ok) {
    if (ok) {
        console.log("利用率和满足率更新成功");
    } else {
        console.log("更新失败");
    }
});
```

**请求参数说明：**
- `id`: 要更新的记录ID（必填）
- `ryzddlyl`: 人员最大利用率（选填，浮点数，建议范围 0.00 ~ 1.00）
- `zbzddlyl`: 装备最大利用率（选填，浮点数，建议范围 0.00 ~ 1.00）
- `rymzl`: 人员满足率（选填，浮点数，建议范围 0.00 ~ 1.00）
- `zbmzl`: 装备满足率（选填，浮点数，建议范围 0.00 ~ 1.00）
- 字段均为选填，只更新提供的字段
- `update_time` 会自动更新为当前时间

**返回值：**
- `true`: 更新成功
- `false`: 更新失败（可能是ID不存在或JSON格式错误）

**使用场景：**
- 当想定执行过程中或执行完成后，需要更新资源利用率和满足率数据时使用
- 可以单独更新某一个字段，无需同时提供所有字段
- 例如只更新人员最大利用率：`{"id": "xxx", "ryzddlyl": 0.85}`

## 完整使用示例

### 示例1：获取并渲染想定列表

```javascript
// 请求所有想定
qtClient.queryScenarioReq();

// 处理返回数据
qtClient.queryScenario.connect(function (jsonStr) {
    var result = JSON.parse(jsonStr);

    console.log("共有 " + result.count + " 条想定记录");

    // 遍历显示
    result.data.forEach(function(scenario) {
        console.log("想定名称：" + scenario.xdmc);
        console.log("机场：" + scenario.jc);
        console.log("状态：" + scenario.zt);
        console.log("开始时间：" + scenario.kssj);
        console.log("---");
    });
});
```


## 注意事项

1. **WebSocket连接**
   - 确保与后端WebSocket服务器已建立连接
   - 服务器地址：`ws://localhost:54321`

2. **JSON格式**
   - 所有JSON数据需要使用 `JSON.stringify()` 序列化后发送
   - 接收到的JSON字符串需要使用 `JSON.parse()` 解析

3. **时间格式**
   - 所有时间字段统一使用格式：`yyyy-MM-dd HH:mm:ss`
   - 示例：`2025-10-12 08:00:00`

4. **状态值规范**
   - 建议使用统一的状态值：`草稿`、`进行中`、`已完成`
   - 前端可以提供下拉选择而不是自由输入

5. **ID自动生成**
   - 添加记录时无需提供ID，系统会自动生成
   - ID格式：时间戳（精确到微秒）+ UUID前6位
   - 示例：`20251108232312345678ABC`

6. **错误处理**
   - 添加/查询失败时会返回空字符串 `""`
   - 删除/编辑失败时会返回 `false`
   - 建议在前端添加相应的错误提示

7. **信号连接**
   - 建议在页面初始化时连接所有信号
   - 避免重复连接同一个信号

8. **数据刷新**
   - 添加、删除、编辑操作成功后，建议重新查询列表以保持数据同步

### 示例7：更新想定的利用率和满足率

```javascript
// 场景：想定执行完成后，更新资源利用率和满足率
function updateScenarioRates(scenarioId) {
    // 假设从计算模块获取到了这些数据
    var rateData = {
        "id": scenarioId,
        "ryzddlyl": 0.85,  // 人员最大利用率 85%
        "zbzddlyl": 0.92,  // 装备最大利用率 92%
        "rymzl": 0.78,     // 人员满足率 78%
        "zbmzl": 0.88      // 装备满足率 88%
    };

    qtClient.updateScenarioRateFieldsReq(JSON.stringify(rateData));

    qtClient.updateScenarioRateFields.connect(function (ok) {
        if (ok) {
            console.log("利用率和满足率更新成功");
            // 刷新想定详情显示
            qtClient.queryScenarioByIdReq(scenarioId);
        } else {
            console.error("更新失败");
        }
    });
}

// 单独更新某一项数据
function updatePersonnelUtilization(scenarioId, rate) {
    var data = {
        "id": scenarioId,
        "ryzddlyl": rate  // 只更新人员最大利用率
    };

    qtClient.updateScenarioRateFieldsReq(JSON.stringify(data));

    qtClient.updateScenarioRateFields.connect(function (ok) {
        if (ok) {
            console.log("人员最大利用率已更新为 " + (rate * 100) + "%");
        }
    });
}
```
