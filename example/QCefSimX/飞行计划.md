# 飞行计划管理前端接口文档

## 概述

飞行计划模块由两张核心数据表组成：
1. **飞机实体表（aircraft_entity）**：管理想定中的具体飞机实例
2. **飞行任务表（flight_task）**：管理每架飞机的具体飞行任务

所有接口通过WebSocket与后端交互，使用 `qtClient` 对象调用，数据格式为JSON。

---

## 数据库表结构

### 1. 飞机实体表（aircraft_entity）

| 字段名 | 类型 | 说明 | 是否必填 |
|--------|------|------|----------|
| id | TEXT | 唯一ID（自动生成） | 是 |
| fjbh | TEXT | 飞机编号 | 是 |
| xdid | TEXT | 想定ID | 是 |
| jxid | TEXT | 机型ID | 是 |
| bzdj | TEXT | 保障等级 | 否 |
| create_time | TEXT | 创建时间（自动生成） | 是 |
| update_time | TEXT | 更新时间（自动更新） | 是 |

### 2. 飞行任务表（flight_task）

| 字段名 | 类型 | 说明 | 是否必填 |
|--------|------|------|----------|
| id | TEXT | 唯一ID（自动生成） | 是 |
| fjstid | TEXT | 飞机实体ID | 是 |
| qfsj | TEXT | 起飞时间 | 是 |
| jlsj | TEXT | 降落时间 | 是 |
| create_time | TEXT | 创建时间（自动生成） | 是 |
| update_time | TEXT | 更新时间（自动更新） | 是 |

### 1.2 添加飞机实体

**前端调用：**
```javascript
// 构造要添加的数据
var newAircraft = {
    "fjbh": "003",
    "xdid": "20251108232312345678ABC",
    "jxid": "20251109144639678678cc1ae7",
    "bzdj": "一级"
};

// 发送请求
qtClient.queryAircraftEntityAddReq(JSON.stringify(newAircraft));

// 监听返回结果
qtClient.queryAircraftEntityAdd.connect(function (jsonStr) {
    if (jsonStr) {
        console.log("添加成功：", jsonStr);
        var newRecord = JSON.parse(jsonStr);
    } else {
        console.log("添加失败");
    }
});
```

**请求参数说明：**
- `fjbh`: 飞机编号（必填）
- `xdid`: 想定ID（必填）
- `jxid`: 机型ID（必填）
- `bzdj`: 保障等级，建议值：一级、二级、三级（选填）

**返回结果：**
成功时返回完整的新记录（包含自动生成的id），失败时返回空字符串

## 三、完整使用示例

### 示例1：创建完整飞行计划

```javascript
// 第一步：创建飞机实体
var newAircraft = {
    "fjbh": "J20-001",

    "bzdj": "一级"
};

qtClient.queryAircraftEntityAddReq(JSON.stringify(newAircraft));

qtClient.queryAircraftEntityAdd.connect(function (jsonStr) {
    if (jsonStr) {
        var aircraft = JSON.parse(jsonStr);
        var aircraftEntityId = aircraft.id;

        console.log("飞机创建成功，ID：", aircraftEntityId);

        // 第二步：为该飞机创建飞行任务

            "fjstid": aircraftEntityId,

            "jlsj": "2025-10-12 10:30:00"
        };

        qtClient.queryFlightTaskAddReq(JSON.stringify(newTask));
    }
});

qtClient.queryFlightTaskAdd.connect(function (jsonStr) {
    if (jsonStr) {
        console.log("飞行任务创建成功");
    }
});
```

### 示例6：删除想定时清理相关数据

```javascript
function deleteScenarioAndRelatedData(scenarioId) {
    // 第一步：查询该想定下的所有飞机
    qtClient.queryAircraftEntityByScenarioIdReq(scenarioId);

    qtClient.queryAircraftEntityByScenarioId.connect(function (jsonStr) {
        var result = JSON.parse(jsonStr);

        // 第二步：删除每架飞机的飞行任务
        result.data.forEach(function(aircraft) {
            qtClient.queryFlightTaskByAircraftEntityIdReq(aircraft.id);
        });
    });

    var aircraftToDelete = [];

    qtClient.queryFlightTaskByAircraftEntityId.connect(function (jsonStr) {
        var result = JSON.parse(jsonStr);

        if (result.count > 0) {
            var aircraftId = result.data[0].fjstid;

            // 删除该飞机的所有任务
            result.data.forEach(function(task) {
                qtClient.queryFlightTaskDelReq(task.id);
            });

            // 记录需要删除的飞机ID
            if (aircraftToDelete.indexOf(aircraftId) === -1) {
                aircraftToDelete.push(aircraftId);
            }
        }
    });

    qtClient.queryFlightTaskDel.connect(function (ok) {
        // 任务删除完成后，删除飞机实体
        aircraftToDelete.forEach(function(aircraftId) {
            qtClient.queryAircraftEntityDelReq(aircraftId);
        });
    });
}
```

    console.log("该飞机有 " + result.count + " 个飞行任务");
    result.data.forEach(function(task) {
        console.log("起飞：" + task.qfsj + " -> 降落：" + task.jlsj);
    });
});

## 五、注意事项

1. **数据关联关系**
   - 飞机实体通过 `xdid` 关联到想定
   - 飞机实体通过 `jxid` 关联到机型
   - 飞行任务通过 `fjstid` 关联到飞机实体
   - 删除想定时，建议先删除相关飞机的所有飞行任务，再删除飞机实体

2. **时间格式**
   - 所有时间字段统一使用格式：`yyyy-MM-dd HH:mm:ss`
   - 示例：`2025-10-12 08:00:00`

3. **保障等级规范**
   - 建议使用统一的保障等级值：`特级`、`一级`、`二级`、`三级`

4. **ID生成规则**
   - 所有ID由系统自动生成，格式：时间戳（精确到微秒）+ UUID前6位
   - 添加记录时无需提供ID

5. **查询排序**
   - 飞机实体查询默认按创建时间倒序（最新的在前）
   - 飞行任务查询默认按起飞时间升序（最早的在前）

6. **WebSocket连接**
   - 服务器地址：`ws://localhost:54321`
   - 确保在调用接口前已建立连接

7. **JSON格式处理**
   - 发送数据时使用 `JSON.stringify()`
   - 接收数据时使用 `JSON.parse()`

8. **错误处理**
   - 添加/查询失败时返回空字符串 `""`
   - 删除/编辑失败时返回 `false`
   - 建议在前端添加相应的错误提示和异常处理

9. **数据刷新策略**
   - 增删改操作成功后，建议重新查询列表以保持数据同步
   - 对于实时性要求高的场景，可以考虑定时轮询

10. **业务逻辑建议**
    - 创建飞行计划的典型流程：选择想定 → 添加飞机实体 → 为飞机添加飞行任务
    - 修改飞行计划时，可以只修改任务时间，不需要修改飞机实体
    - 建议在前端实现飞行任务的时间冲突检测
