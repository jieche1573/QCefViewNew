
根据机型ID查询所有能维修该机型的岗位

```JSON
  qtClient.queryPositionSkillByAircraftReq("20251109144639678678cc1ae7");
  qtClient.queryPositionSkillByAircraft.connect(function (jsonStr) {
    alert(jsonStr)
  });
```

返回所有能维修该机型的岗位及对应能力系数。

## 使用场景说明

1. **设置岗位多能**：使用批量添加接口，为一个岗位一次性设置多个机型的维修能力
   - 例如：机械岗位可以维修JJ1(0.8)、JJ2(0.6)、JJ3(0.3)

2. **查询岗位能力**：根据岗位ID查询，了解该岗位可以维修哪些机型
   - 用于岗位能力评估和任务分配

3. **查询机型需求**：根据机型ID查询，了解哪些岗位可以维修该机型
   - 用于维修任务的岗位资源规划

4. **更新能力系数**：随着岗位技能提升，可以更新对某个机型的能力系数
   - 例如：从0.6提升到0.8

5. **重置岗位能力**：删除岗位的所有机型能力后，重新批量添加
   - 用于岗位能力的全面更新
