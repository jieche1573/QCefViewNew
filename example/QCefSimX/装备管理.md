# 装备管理接口文档

## 概述

装备管理模块用于管理各类装备和设备信息。支持区分通用设备和专用设备，专用设备可以关联到特定的飞机机型。

**设计原则：低耦合**
- 本模块只返回机型ID（zyjx），不返回机型名称
- 前端需要显示机型名称时，应调用机型管理接口 `AircraftModel::queryRecordById()` 查询

## 数据结构

### 装备记录结构

```json
{
  "id": "20251108232312345678ABC",
  "sbid": "001",
  "sbmc": "电源车",
  "lx": "装备",
  "sfzy": "专用设备",
  "zyjx": "20251109144639678678cc1ae7",  // 专用机型ID
  "xqjs": "用于提供地面电源支持",
  "create_time": "2025-11-08 23:23:12",
  "update_time": "2025-11-08 23:23:12"
}
```

**字段说明：**
- **id**: 唯一ID（时间戳精确到微秒 + UUID前6位）
- **sbid**: 设备ID
- **sbmc**: 设备名称
- **lx**: 类型（装备/设备）
- **sfzy**: 是否专用（通用设备/专用设备）
- **zyjx**: 专用机型ID（关联aircraft_model表的id，通用设备时为空）
- **xqjs**: 详情介绍
- **create_time**: 创建时间
- **update_time**: 更新时间

**重要说明：**
- 当 **sfzy** 为 **"专用设备"** 时，**zyjx** 存储机型ID
- 当 **sfzy** 为 **"通用设备"** 时，**zyjx** 字段为空
- 本接口只返回机型ID，不返回机型名称，保持模块低耦合

### 2. 添加装备

```javascript

  console.log(newJsonStr);
});
```

**入参示例（通用设备）：**
```json
{
  "sbid": "003",
  "sbmc": "维修工具车",
  "lx": "设备",
  "sfzy": "通用设备",
  "xqjs": "通用维修工具"
}
```

**入参示例（专用设备）：**
```json
{
  "sbid": "004",
  "sbmc": "专用测试设备",
  "lx": "设备",
  "sfzy": "专用设备",
  "zyjx": "20251109144639678678cc1ae7",
  "xqjs": "歼二十专用测试设备"
}
```

**返回数据：** 包含自动生成ID和时间戳的完整记录，例如：
```json
{
  "id": "20251108232312345678ABC",
  "sbid": "004",
  "sbmc": "专用测试设备",
  "lx": "设备",
  "sfzy": "专用设备",
  "zyjx": "20251109144639678678cc1ae7",
  "xqjs": "歼二十专用测试设备",
  "create_time": "2025-11-08 23:23:12",
  "update_time": "2025-11-08 23:23:12"
```

**注意：**
- 如果选择 **"通用设备"**，即使提供了 **zyjx** 字段，也会被自动清空
- 如果选择 **"专用设备"**，必须提供有效的 **zyjx**（机型ID）

## 使用场景

### 场景1: 添加通用设备

```javascript
const equipmentData = {
  sbid: "005",
  sbmc: "通用维修平台",
  lx: "装备",
  sfzy: "通用设备",
  xqjs: "适用于所有机型的维修平台"
};

qtClient.queryEquipmentAddReq(JSON.stringify(equipmentData));
qtClient.queryEquipmentAdd.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);
  console.log("添加成功，ID:", result.id);
  console.log("zyjx为空:", result.zyjx === "");
});
```

### 场景2: 添加专用设备

```javascript
const equipmentData = {
  sbid: "006",
  sbmc: "歼二十专用测试台",
  lx: "设备",
  sfzy: "专用设备",
  zyjx: "20251109144639678678cc1ae7", // 机型ID
  xqjs: "专为歼二十设计的测试设备"
};

qtClient.queryEquipmentAddReq(JSON.stringify(equipmentData));
qtClient.queryEquipmentAdd.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);
  console.log("添加成功，ID:", result.id);
  console.log("机型ID:", result.zyjx);
});
```

### 场景3: 查询并显示机型名称

前端获取装备列表后，需要显示机型名称时，应调用机型管理接口：

```javascript
qtClient.queryEquipmentReq();
qtClient.queryEquipment.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);

  result.data.forEach(equipment => {
    // 如果是专用设备且有机型ID，查询机型名称
    if (equipment.sfzy === "专用设备" && equipment.zyjx) {
      qtClient.queryFlyReq(); // 或使用 queryRecordById(equipment.zyjx)
      qtClient.queryFly.connect(function (modelsJsonStr) {
        const models = JSON.parse(modelsJsonStr);
        const model = models.data.find(m => m.id === equipment.zyjx);
        if (model) {
          console.log(`设备：${equipment.sbmc}，机型：${model.jxmc}`);
        }
      });
    } else {
      console.log(`设备：${equipment.sbmc}，通用设备`);
    }
  });
});
```

**推荐做法：** 前端可以先加载所有机型数据到内存，然后根据ID匹配：

```javascript
// 1. 先加载所有机型
let modelMap = {};
qtClient.queryFlyReq();
qtClient.queryFly.connect(function (jsonStr) {
  const models = JSON.parse(jsonStr);
  // 构建机型ID到名称的映射
  models.data.forEach(model => {
    modelMap[model.id] = model.jxmc;
  });

  // 2. 加载装备列表
  qtClient.queryEquipmentReq();
  qtClient.queryEquipment.connect(function (equipJsonStr) {
    const equipments = JSON.parse(equipJsonStr);
    equipments.data.forEach(equip => {
      const modelName = equip.zyjx ? modelMap[equip.zyjx] : "通用";
      console.log(`${equip.sbmc} - ${modelName}`);
    });
  });
});
```

### 场景4: 将专用设备改为通用设备

```javascript
const updateData = {
  id: "20251110103015684684086dfc",
  sfzy: "通用设备"
};

qtClient.queryEquipmentEditReq(JSON.stringify(updateData));
qtClient.queryEquipmentEdit.connect(function (ok) {
  if (ok) {
    console.log("更新成功，zyjx字段已自动清空");
  }
});
```

### 场景5: 按机型筛选专用设备

```javascript
qtClient.queryEquipmentReq();
qtClient.queryEquipment.connect(function (jsonStr) {
  const result = JSON.parse(jsonStr);
  // 过滤出特定机型的专用设备
  const modelId = "20251109144639678678cc1ae7";
  const filtered = result.data.filter(item => item.zyjx === modelId);
  console.log(`该机型的专用设备共${filtered.length}个`);
});
```

## 注意事项

1. **低耦合设计**：
   - 装备管理接口只返回机型ID（**zyjx**），不返回机型名称
   - 前端需要显示机型名称时，应调用机型管理接口查询
   - 推荐前端先加载所有机型数据，构建ID到名称的映射表

2. **专用/通用设备切换**：
   - 选择"通用设备"时，**zyjx** 字段会自动清空
   - 选择"专用设备"时，必须提供有效的 **zyjx**（机型ID）

3. **数据一致性**：
   - 删除机型前应检查是否有专用设备关联到该机型
   - 可以通过查询所有设备后过滤 **zyjx** 字段来检查

4. **性能优化**：
   - 前端建议一次性加载所有机型，缓存到内存中
   - 避免为每个设备单独查询机型信息

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | String | 自动生成 | 唯一ID |
| sbid | String | 是 | 设备ID |
| sbmc | String | 是 | 设备名称 |
| lx | String | 是 | 类型（装备/设备） |
| sfzy | String | 是 | 是否专用（通用设备/专用设备） |
| zyjx | String | 专用设备必填 | 专用机型ID（关联aircraft_model表） |
| xqjs | String | 否 | 详情介绍 |
| create_time | String | 自动生成 | 创建时间 |
| update_time | String | 自动生成 | 更新时间 |
